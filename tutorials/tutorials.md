# Tutorials and Learning Resources

## 1. Crossref REST API — Official Documentation

Learn DOI lookup, work metadata retrieval, search, filtering, and responsible API use. This is the recommended starting point for programmatic bibliographic verification.

[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)

## 2. OpenAlex API Reference

Covers the scholarly knowledge graph's works, authors, sources, institutions, search, filters, paging, and field selection. Useful for implementing candidate-reference search when a generated citation is incomplete.

[OpenAlex API](https://help.openalex.org/api/)

## 3. Semantic Scholar API Documentation

Provides the API surface for paper metadata, authors, citations, references, and related scholarly information. Useful for building citation-resolution and graph-analysis tools.

[Semantic Scholar API](https://api.semanticscholar.org/api-docs/)

## 4. GROBID Documentation

Explains PDF-to-structured-document processing and reference extraction. This is useful when the source evidence exists only as a PDF and must be converted into machine-readable text and bibliography structures.

[GROBID](https://github.com/grobidOrg/grobid)

## 5. ACL Anthology Citation FAQ

Explains how to obtain authoritative citation metadata, BibTeX, citation keys, and bulk bibliographic exports for ACL publications.

[ACL Anthology — How do I cite papers?](https://aclanthology.org/faq/bib/)

## 6. SciFact

A practical entry point for scientific claim verification, with data, training scripts, evaluation, and examples.

[SciFact repository](https://github.com/allenai/scifact)

## 7. DOI Handbook

A technical reference for DOI syntax, resolution, metadata, interoperability, and identifier services. Useful for understanding why a DOI match is strong evidence of identity but still must be checked against metadata.

[DOI Handbook](https://www.doi.org/doi-handbook/html/)

## 8. Pyserini Search Guide

A practical guide to sparse, dense, and hybrid retrieval. Useful for the evidence-retrieval stage of a citation-drift pipeline.

[Pyserini search guide](https://github.com/castorini/pyserini/blob/master/docs/usage-search.md)
