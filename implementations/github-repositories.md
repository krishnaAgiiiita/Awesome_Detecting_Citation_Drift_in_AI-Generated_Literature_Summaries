# GitHub Implementations

These are existing research/code repositories selected for technical relevance, documentation, and direct connection to citation, factuality, retrieval, or scientific-text verification.

## 1. ScienceNLP-Lab/Citation-Integrity

**What it implements:** Data and NLP models for assessing citation integrity in biomedical publications, including evidence-sentence retrieval and citation-accuracy modeling.  
**Why relevant:** Closely matches claim-to-evidence citation verification.  
[Repository](https://github.com/ScienceNLP-Lab/Citation-Integrity/)

## 2. KathCYM/CiteGuard

**What it implements:** Retrieval-aware citation-attribution validation with CLI and web UI support.  
**Why relevant:** Directly targets citation attribution alignment and alternative valid citations.  
[Repository](https://github.com/KathCYM/CiteGuard)

## 3. shiiiikw/CiteAudit

**What it implements:** Automated academic-citation verification using URL probing, web/search evidence, and an LLM judge.  
**Why relevant:** Demonstrates a practical multi-stage pipeline for detecting hallucinated or fake references.  
[Repository](https://github.com/shiiiikw/CiteAudit)

## 4. princeton-nlp/ALCE

**What it implements:** Benchmark and systems for generating text with citations, including retrieval and automatic citation evaluation.  
**Why relevant:** Provides reproducible baselines for citation-aware generation.  
[Repository](https://github.com/princeton-nlp/ALCE)

## 5. AkariAsai/self-rag

**What it implements:** Official Self-RAG implementation with retrieval, generation, critique, training, and inference components.  
**Why relevant:** Shows how adaptive retrieval and self-reflection can improve grounding and citation behavior.  
[Repository](https://github.com/AkariAsai/self-rag)

## 6. google-deepmind/long-form-factuality

**What it implements:** LongFact, SAFE, F1@K, and an evaluation pipeline for long-form factuality.  
**Why relevant:** Provides an established decomposition-and-verification pattern that can be adapted to citation-supported claims.  
[Repository](https://github.com/google-deepmind/long-form-factuality)

## 7. allenai/scifact

**What it implements:** Data, models, scripts, and evaluation for scientific claim verification.  
**Why relevant:** Useful as a concrete evidence-retrieval and claim-verification baseline.  
[Repository](https://github.com/allenai/scifact)

## 8. allenai/s2orc

**What it implements:** Scientific-paper corpus resources and processing support for large-scale scholarly NLP and text mining.  
**Why relevant:** Supplies the type of machine-readable scholarly corpus needed for retrieval and citation-network experiments.  
[Repository](https://github.com/allenai/s2orc)
