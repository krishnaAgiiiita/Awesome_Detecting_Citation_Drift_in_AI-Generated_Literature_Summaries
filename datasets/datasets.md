# Datasets

## 1. SciFact

**Source:** Allen Institute for AI  
**Task:** Scientific claim verification and evidence retrieval.  
**Why relevant:** Provides claims paired with scientific evidence and supports research on whether retrieved passages substantiate a claim.  
**License / access:** See the official project repository and dataset terms.  
[Official repository](https://github.com/allenai/scifact)

## 2. CiteME

**Source:** Bethge Lab / CiteME project  
**Task:** Citation attribution — identify the paper referenced by a marked citation in a scientific excerpt.  
**Why relevant:** Directly models the claim-to-citation attribution problem central to citation drift.  
**License:** Dataset is documented as CC-BY-4.0 by the project.  
[Project](https://www.citeme.ai/) · [Code](https://github.com/bethgelab/CiteME)

## 3. CiteWorth

**Source:** University of Copenhagen / CopenLU  
**Task:** Cite-worthiness detection at sentence level with paragraph context.  
**Why relevant:** Helps study when scientific text should carry a citation and can be used as a preprocessing stage before attribution.  
**License:** Dataset terms are provided by the project.  
[Project repository](https://github.com/copenlu/cite-worth)

## 4. CL-SciSumm Corpus

**Source:** WING-NUS  
**Task:** Scientific document summarization, citance-to-reference-span identification, and information-facet annotation.  
**Why relevant:** Provides explicit links between citation sentences and source-paper spans, making it useful for evidence alignment.  
[Official repository](https://github.com/WING-NUS/scisumm-corpus)

## 5. S2ORC — Semantic Scholar Open Research Corpus

**Source:** Allen Institute for AI / Semantic Scholar  
**Task:** Large-scale scientific-paper corpus for NLP and text mining.  
**Why relevant:** Supplies machine-readable scientific text and bibliographic/citation structure for retrieval and citation analysis.  
**License:** Current distribution is documented as ODC-By 1.0.  
[Official repository](https://github.com/allenai/s2orc)

## 6. SciDocs

**Source:** Allen Institute for AI  
**Task:** Evaluation suite for scientific-document representations, including citation-related tasks.  
**Why relevant:** Useful for evaluating scholarly representations and retrieval components in citation-aware systems.  
**Note:** The project recommends SciRepEval for newer embedding evaluation.  
[Official repository](https://github.com/allenai/scidocs)
